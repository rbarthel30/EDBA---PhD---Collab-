# References

Reference materials — FDA documentation, methodology guides, code snippets, and other resources that support the project but are not academic papers (those live in `literature/`).

## Subfolders to create as needed

- `fda-docs/` — FDA guidance PDFs (gitignore PDFs if redistribution is restricted)
- `methodology/` — Event-study templates, DiD code snippets, robust SE references
- `data-dictionaries/` — Variable definitions for CRSP, Compustat, IBES extracts

## Useful starting links
